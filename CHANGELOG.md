# Changelog

## v1.0.0

Initial public release of ReconLens.

### Highlights

- Consent-first browser privacy demonstration platform.
- Electron operator dashboard.
- HTTPS participant access through Cloudflare Tunnel or ngrok.
- Automatic browser, device, network, and display information collection.
- Permission demonstrations for location, camera, microphone, notifications, and clipboard.
- Real-time dashboard updates through WebSocket.
- Session timeline, map view, and reports.
- Participant-controlled photo sharing after camera permission.
